# 05 — Copy and content (generic copy is a bigger tell than visuals)

## Rules
- Write from real product facts: routes, steps, what is verified, who sees what.
- Short, concrete sentences. Name actual things: "gate", "seat", "pickup point", "college email".
- Banned words/phrases: seamless, effortless, revolutionise/revolutionize, unlock, supercharge, elevate, next-gen, cutting-edge, "built for the modern student", "your journey starts here" (unless you can defend it).
- No headline pattern "Verb your X, Y your Z." on every section.
- No fake numbers. If there is no data, say what the feature does, not how popular it is.
- Safety copy: plain, calm, factual. State what verification checks and what it does not. Do not promise safety outcomes the system cannot guarantee.
- Women-Only carpools: describe exactly how eligibility is determined in the product; do not overclaim.
- Error messages: say what happened and what to do next. No jokes on errors involving safety, verification or payments.
- Empty states: one sentence + one action. Mascot optional.

## Language
If Hindi or regional language is used in UI, have a native reader review. Keep English as the base unless the product actually supports language switching.

## Microcopy inventory (agent produces, owner reviews)
Buttons, empty states, errors, success messages, verification statuses, ride statuses. Keep one list in `content/copy.md` so tone stays consistent.

## Tone test
Read a paragraph aloud. If it could be pasted onto any other startup site, rewrite it with a detail only CampusRide has.
